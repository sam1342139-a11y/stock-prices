# fcn-monitor/（FCN 每日燈號監控）

每天美股收盤價抓好後，自動計算每檔 FCN 商品離敲出、敲入還差多少，並寄 Email 給你。

| 檔案 | 用途 |
|---|---|
| `monitor.py` | 計算燈號並寄信的程式 |

## 什麼時候執行
每日股價（`update-prices`）抓完後**自動接著執行**，大約台灣時間週二到週六早上 06:35。
排程設定在 `.github/workflows/fcn-monitor.yml`。
想立刻手動執行：GitHub 上方點 **Actions** → **fcn-monitor** → **Run workflow**。

## 燈號規則

| 燈號 | 意思 |
|---|---|
| 🔴 | 至少一檔標的**已跌破敲入價** |
| 🟠 | 最弱標的離敲入價**不到 10%** |
| 🔷 | 最弱標的離敲出價**不到 3%**，即將敲出 |
| 🔵 | 所有標的都已**達到敲出價** |
| 🟢 | 正常 |
| ⚪ | 抓不到價格 |

※ 以每日收盤價估算，實際是否敲出或敲入，以商品條件書的觀察日與規則為準。

## 商品資料放在哪裡？（重要）
**商品條件不放在任何檔案裡**，而是存在 GitHub 密鑰，外人看不到：
GitHub → **Settings** → **Secrets and variables** → **Actions**

| 密鑰名稱 | 內容 |
|---|---|
| `FCN_PRODUCTS` | 商品條件（格式見下方），**不要放客戶姓名** |
| `GMAIL_USER` | 寄信用的 Gmail 地址 |
| `GMAIL_APP_PASSWORD` | 該 Gmail 的「應用程式密碼」（16 碼，不是登入密碼） |
| `MAIL_TO` | 收信地址，多個用逗號分隔；不填就寄給 `GMAIL_USER` |

`FCN_PRODUCTS` 格式（每檔標的填敲出價 `ko`、敲入價 `ki`，`maturity` 到期日可不填）：

```json
[
  {"code": "商品代號", "maturity": "2027-01-06",
   "legs": [{"t": "TSM", "ko": 418.45, "ki": 251.07},
            {"t": "AVGO", "ko": 446.77, "ki": 268.06}]}
]
```

要新增、刪除商品或修改條件，請找 Claude 幫你產生新的內容，再貼到 `FCN_PRODUCTS` 密鑰（按 Update）。

⚠️ 連結標的必須在每日股價追蹤的 26 檔清單裡，不在清單裡的請找 Claude 加入。
⚠️ 標的如果**股票分割**（例如 1 拆 3），敲出價、敲入價也要跟著調整，否則燈號會錯。
